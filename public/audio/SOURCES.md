All are mono PCM16 WAVs. Character scroll is mapped to mouse hover/keyboard focus;
character enter is mapped to navigation selection; pass good plays when the
first-visit intro's hack matches the password. These are terminal effects,
not the separate Pip-Boy/menu highlight and select assets.
