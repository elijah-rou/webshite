# Code font

`IosevkaTermSlab-Regular.woff2` and `IosevkaTermSlab-Bold.woff2` are subsets of
IosevkaTermSlab Nerd Font (Iosevka 34.8.0, Nerd Fonts 3.5.1), made with
`scripts/subset-iosevka.sh`. They keep Latin characters, punctuation and arrows
and drop hinting and the Nerd Font icon glyphs. Iosevka is © 2015-2026 Renzhi Li
and licensed under the SIL Open Font License 1.1; see `IOSEVKA-LICENSE.md`.
